
# Set 2 - Question 3: Longest Attendance Streak

**Difficulty:** Easy (16 Marks)

## Scenario
A college tracks daily attendance counts for a class over n days. A good day is a day with at least T students present.

## Problem Statement
Given n daily attendance counts and a threshold T, find the length of the longest consecutive sequence of days in which every day's attendance is greater than or equal to T.

If there is no good day, print 0.

## Input Format
- First line: Two integers n and T
- Second line: n space-separated attendance counts

## Output Format
Print the length of the longest attendance streak.

## Constraints
- 1 <= n <= 10^5
- 1 <= T <= 10^4
- 0 <= attendance <= 10^4

## Sample Input
10 30
28 35 40 31 30 12 33 36 29 41

## Sample Output
4

## Approach
Traverse the array and maintain a counter for consecutive good days. Reset the counter whenever attendance falls below T. Keep track of the longest streak.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
