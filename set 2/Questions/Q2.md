
# Set 2 - Question 2: First Unique Visitor

**Difficulty:** Easy (16 Marks)

## Scenario
A website records visitor IDs in the order they visit the landing page. The marketing team wants to find the earliest visitor who visited exactly once.

## Problem Statement
Given an array of n visitor IDs, find the first ID that occurs exactly once in the entire array.

If every ID appears at least twice, print -1.

## Input Format
- First line: Integer n
- Second line: n space-separated visitor IDs

## Output Format
Print the first non-repeating visitor ID, or -1.

## Constraints
- 1 <= n <= 10^5
- 1 <= ID <= 10^9

## Sample Input
10
17 23 17 8 23 42 8 5 42 17

## Sample Output
5

## Approach
Use a dictionary to count the frequency of each visitor ID. Traverse the array again and return the first ID whose frequency is 1.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
