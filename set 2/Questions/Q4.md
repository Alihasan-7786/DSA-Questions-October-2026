
# Set 2 - Question 4: Daily Sales Range Reports

**Difficulty:** Medium (26 Marks)

## Scenario
A shop records daily sales for n days. The owner receives multiple queries asking for the total sales between two days.

## Problem Statement
Given an array of daily sales and q queries, each containing two indices l and r, find the sum of elements from index l to r (inclusive).

Each query should be answered efficiently.

## Input Format
- First line: Two integers n and q
- Second line: n space-separated daily sales
- Next q lines: Two integers l and r

## Output Format
Print the sum for each query on a separate line.

## Constraints
- 1 <= n, q <= 10^5
- 0 <= sales[i] <= 10^4
- 0 <= l <= r <= n-1
- Built-in sum() and itertools.accumulate are not allowed.

## Sample Input
8 4
5 3 8 2 7 1 9 4
0 2
3 5
1 7
4 4

## Sample Output
16
10
34
7

## Approach
Use the Prefix Sum technique. Create a prefix array where each position stores the cumulative sum of previous elements. Answer each query using prefix[r+1] - prefix[l].

## Complexity
- Time Complexity: O(n + q)
- Space Complexity: O(n + q)
