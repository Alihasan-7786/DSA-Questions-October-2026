
# Set 2 - Question 1: Campus Election Winner

**Difficulty:** Easy (16 Marks)

## Scenario
In a student-council election, every ballot carries a candidate ID. A candidate wins if they receive more than half of all votes.

## Problem Statement
Given an array of n candidate IDs, find the candidate who appears strictly more than floor(n/2) times.

The input guarantees that such a candidate exists and is unique.

## Input Format
- First line: Integer n
- Second line: n space-separated candidate IDs

## Output Format
Print the winning candidate ID.

## Constraints
- 1 <= n <= 10^5
- 1 <= ID <= 10^9
- A majority candidate always exists.

## Sample Input
9
3 2 3 3 1 3 2 3 3

## Sample Output
3

## Approach
Use the Boyer-Moore Voting Algorithm. Maintain a candidate and a count. Increase the count when the current element matches the candidate and decrease it otherwise.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
