
# Set 2 - Question 5: Delivery Route Rotation

**Difficulty:** Medium (26 Marks)

## Scenario
A courier company schedules n delivery stops. Each day, the route is rotated to the right by k positions.

## Problem Statement
Given an array of n stop IDs and an integer k, rotate the array to the right by k positions.

The value of k may be 0, equal to n or greater than n.

Modify the original array without using slicing tricks or built-in reversal helpers.

## Input Format
- First line: Two integers n and k
- Second line: n space-separated stop IDs

## Output Format
Print the rotated array on one line.

## Constraints
- 1 <= n <= 10^5
- 0 <= k <= 10^9
- 1 <= stop ID <= 10^9

## Sample Input
7 3
1 2 3 4 5 6 7

## Sample Output
5 6 7 1 2 3 4

## Approach
Use the array reversal technique:
1. Reverse the entire array.
2. Reverse the first k elements.
3. Reverse the remaining elements.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
