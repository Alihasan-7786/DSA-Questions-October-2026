
# Q3 – Nearly Sorted Event Log

**Difficulty:** Easy

## Problem Statement
A server records event timestamps that are almost in order. Some events arrive late due to network delays.

Sort the `n` timestamps in non-decreasing order using **Insertion Sort**. Take each element and move it left past every strictly greater element.

Print the sorted list on the first line and the total number of single-position shifts on the second line. Moving one element one place to the right counts as one shift.

Built-in sorting is not allowed.

## Input Format
- First line: Integer `n`.
- Second line: `n` space-separated timestamps.

## Output Format
- First line: Sorted timestamps.
- Second line: Total number of shifts performed.

## Constraints
- `1 ≤ n ≤ 5000`
- `0 ≤ timestamp ≤ 10^6`

## Sample Input
```text id="v2d9kz"
8
10 20 15 30 40 35 50 45
```

## Sample Output
```text id="f4p8xq"
10 15 20 30 35 40 45 50
3
```

## Approach
Use Insertion Sort. For each element, shift all greater elements one position to the right and insert the current element in its correct position. Count every shift.

## Complexity
- **Time:** O(n²) in the worst case
- **Auxiliary Space:** O(1)
