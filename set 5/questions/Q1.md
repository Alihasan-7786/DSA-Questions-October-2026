
# Q1 – Mock Test Ranking Passes

**Difficulty:** Easy

## Problem Statement
After a mock test, a teacher wants to arrange the students' marks in ascending order using Bubble Sort.

In each pass, compare neighbouring marks from left to right. Swap them only when the left mark is greater than the right mark.

Print the sorted marks on the first line and the number of productive passes on the second line. A productive pass is a pass in which at least one swap happens.

Built-in sorting is not allowed.

## Input Format
- First line: Integer `n`.
- Second line: `n` space-separated marks.

## Output Format
- First line: Sorted marks in ascending order.
- Second line: Number of productive passes.

## Constraints
- `1 ≤ n ≤ 2000`
- `0 ≤ mark ≤ 100`

## Sample Input
```text
5
5 1 4 2 8
```

## Sample Output
```text
1 2 4 5 8
2
```

## Approach
Use Bubble Sort to compare adjacent elements and swap them when they are in the wrong order. Count each pass in which at least one swap occurs.

## Complexity
- **Time:** O(n²) in the worst case
- **Auxiliary Space:** O(1)
