
# Q2 – Fastest Deliveries Podium

**Difficulty:** Easy

## Problem Statement
A courier company records the delivery times of `n` completed orders. It needs the `k` fastest deliveries, listed from fastest to slowest.

Given `n` delivery times and an integer `k`, print the `k` smallest times in non-decreasing order. Duplicates count separately.

Use Selection Sort and stop after `k` rounds. Built-in sorting, `min()` and heaps are not allowed.

## Input Format
- First line: Two integers `n` and `k`.
- Second line: `n` space-separated delivery times.

## Output Format
Print the `k` smallest delivery times in non-decreasing order, separated by spaces.

## Constraints
- `1 ≤ k ≤ n ≤ 3000`
- `1 ≤ time ≤ 10^4`

## Sample Input
```text
7 3
29 14 36 7 21 14 50
```

## Sample Output
```text
7 14 14
```

## Approach
Use Selection Sort for only `k` rounds. In each round, find the smallest element in the unsorted portion and swap it into the current position.

## Complexity
- **Time:** O(n × k)
- **Auxiliary Space:** O(1)
