
# Q4 – Leaderboard Disorder Count

**Difficulty:** Medium

## Problem Statement
A game server lists players' scores in the order they finished their matches. To measure unfairness, the analyst counts pairs where an earlier finisher has a strictly higher score than a later finisher.

Given `n` scores in finishing order, count the pairs of positions `(i, j)` where:

- `i < j`
- `score[i] > score[j]`

Equal scores do not form an inversion.

Print the total number of inversions. Built-in sorting is not allowed. An O(n²) pair check is too slow for the largest inputs.

## Input Format
- First line: Integer `n`.
- Second line: `n` space-separated scores.

## Output Format
Print one integer: the number of inversions.

## Constraints
- `1 ≤ n ≤ 10^5`
- `0 ≤ score ≤ 10^9`

## Sample Input
```text
6
5 3 8 6 2 7
```

## Sample Output
```text
7
```

## Approach
Use Merge Sort. During merging, when an element from the right half is smaller than the current element in the left half, all remaining elements in the left half form inversions with it.

## Complexity
- **Time:** O(n log n)
- **Auxiliary Space:** O(n)
