
# Q5 – K-th Highest Salary

**Difficulty:** Medium

## Problem Statement
An HR analyst has the monthly salaries of `n` employees. Some employees may have the same salary.

Given `n` salaries and an integer `k`, print the k-th largest salary. The value is at position `k` when salaries are arranged in non-increasing order.

- `k = 1` means the maximum salary.
- Duplicates count separately.
- Built-in sorting is not allowed. Use partitioning.

## Input Format
- First line: Two integers `n` and `k`.
- Second line: `n` space-separated salaries.

## Output Format
Print one integer: the k-th largest salary.

## Constraints
- `1 ≤ k ≤ n ≤ 10^5`
- `1 ≤ salary ≤ 10^9`

## Sample Input
```text id="p5xq2a"
9 3
40 25 60 25 90 75 60 30 50
```

## Sample Output
```text id="r7w3kn"
60
```

## Approach
Use the Quickselect partitioning method. Choose a pivot and divide the array into smaller, equal and larger elements. Continue searching only in the section containing the required position.

## Complexity
- **Average Time:** O(n)
- **Worst-case Time:** O(n²)
- **Auxiliary Space:** O(1)
