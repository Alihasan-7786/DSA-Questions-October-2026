
# Q1. Peak Traffic Window

## Problem Statement

A news website records the number of visitors for each of `n` consecutive hours.

Given the hourly visitor counts and a window length `k`, find the largest possible total visitors over any `k` consecutive hours.

Maintain the window total incrementally. Do not use built-in `sum()`, `max()` or slicing inside the loop.

## Input Format
- First line contains two integers `n` and `k`.
- Second line contains `n` space-separated integers representing hourly visitor counts.

## Output Format
Print one integer: the maximum window total.

## Example

**Input:**
```text
9 3
4 2 10 1 3 9 6 5 7
```

**Output:**
```text
20
```

## Approach
Calculate the sum of the first `k` elements. Then slide the window one position at a time by adding the new element and subtracting the element that leaves the window.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
