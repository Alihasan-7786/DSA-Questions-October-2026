
# Q5. Longest Unique Scan Run

## Problem Statement

A conveyor belt scanner reads an item code for every parcel passing by.

Find the longest contiguous segment in which all item codes are different. In other words, no code should appear more than once in that segment.

## Input Format
- First line contains an integer `n`, the number of scanned item codes.
- Second line contains `n` space-separated integers representing the item codes.

## Output Format
Print one integer: the length of the longest segment with no repeated code.

## Example

**Input:**
```text
10
12 7 9 4 5 3 12 6 8 2
```

**Output:**
```text
9
```

## Approach
Use a sliding window and a dictionary to store the most recent index of each item code. If a duplicate appears inside the current window, move the left pointer forward.

## Complexity
- Time Complexity: O(n) average
- Space Complexity: O(n)
