
# Q4. Plagiarism Pattern Scanner

## Problem Statement

A plagiarism checker looks for scrambled copies of a short keyword inside a long document.

Given a text `s` and a keyword `p`, both containing lowercase English letters, find every starting index `i` where the substring of length `|p|` is an anagram of `p`.

An anagram contains exactly the same letters with the same frequencies, but possibly in a different order.

Print all matching indices in increasing order. Overlapping occurrences must also be reported.

Do not use `Counter`, `sorted()` or slicing inside the loop.

## Input Format
- First line contains the string `s`.
- Second line contains the string `p`.

## Output Format
Print all matching starting indices separated by spaces. If no matching index exists, print `None`.

## Example

**Input:**
```text id="v5n6cp"
cbaebabacd
abc
```

**Output:**
```text id="8n7c0a"
0 6
```

## Approach
Use two frequency arrays of size 26 to store character counts. Maintain a sliding window of length equal to the keyword and compare its frequencies with the keyword's frequencies.

## Complexity
- Time Complexity: O(26 × n), effectively O(n)
- Space Complexity: O(1)
