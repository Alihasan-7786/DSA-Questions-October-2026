
# Q3. Strong Average Days

## Problem Statement

A school records the number of students present each day for `n` days.

A strong period is any `k` consecutive days whose average attendance is at least `T`.

Given the daily attendance counts, an integer `k`, and a threshold `T`, count the number of windows of exactly `k` consecutive days whose average is at least `T`.

To avoid fractions, a window qualifies when its sum is at least `k * T`. Overlapping windows are also counted.

## Input Format
- First line contains three integers `n`, `k`, and `T`.
- Second line contains `n` space-separated integers representing daily attendance counts.

## Output Format
Print one integer: the number of qualifying windows.

## Example

**Input:**
```text
8 3 4
2 2 2 2 5 5 5 8
```

**Output:**
```text
3
```

## Approach
Calculate the sum of the first `k` elements. Then slide the window by adding the next element and subtracting the element leaving the window. Count each window whose sum is at least `k * T`.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
