
# Q2. Repeated Login Alert

## Problem Statement

A bank's login-monitoring system receives a sequence of user IDs, one for each login event.

If the same user ID appears twice within `k` events of each other, the system raises a suspicious-activity alert.

Given the `n` user IDs and an integer `k`, check whether there are two different positions `i` and `j` such that:

`i < j` and `j - i <= k`

## Input Format
- First line contains two integers `n` and `k`.
- Second line contains `n` space-separated user IDs.

## Output Format
Print `YES` if a repeated ID is found within distance `k`; otherwise, print `NO`.

## Example

**Input:**
```text id="h9mwzy"
8 2
7 12 5 7 12 9 12 4
```

**Output:**
```text id="3rkk7d"
YES
```

## Approach
Use a dictionary to store the most recent index of each user ID. When an ID appears again, check whether the distance between its current and previous positions is at most `k`.

## Complexity
- Time Complexity: O(n) average
- Space Complexity: O(n)
