
# Question 2 – Price Tier Floor and Ceiling

**Difficulty:** Easy

## Problem Statement

A shop's price list contains the available price tiers in increasing order. The same tier may be listed more than once.

Given a non-decreasing array of `n` prices and a query value `q`, print two values separated by a space:

- **Floor:** The largest price less than or equal to `q`.
- **Ceiling:** The smallest price greater than or equal to `q`.

If a value does not exist, print `None` in its place.

Use binary search.

## Input Format

- Line 1: Integer `n`.
- Line 2: `n` integers in non-decreasing order.
- Line 3: Integer `q`.

## Output Format

Print `floor ceiling`, where each value is an integer or `None`.

## Constraints

- `1 ≤ n ≤ 10^5`
- `-10^9 ≤ price, q ≤ 10^9`

## Sample Input

```text
6
10 20 30 40 50 60
35
```

## Sample Output

```text
30 40
```

## Approach

1. Use binary search to find the first element greater than `q`.
2. The element immediately before it is the floor.
3. Use another binary search to find the first element greater than or equal to `q`.
4. That element is the ceiling.
5. If either index is outside the array, print `None` for that value.

## Complexity Analysis

- **Time Complexity:** `O(log n)` – Two binary searches.
- **Auxiliary Space:** `O(1)` – Only a few variables are used.
