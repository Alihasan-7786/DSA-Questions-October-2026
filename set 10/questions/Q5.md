
# Question 5 – Textbook Allocation for Reading Groups

**Difficulty:** Medium

## Problem Statement

A library has `n` textbooks arranged on a shelf in a fixed order, with known page counts.

The professor splits the class into `m` reading groups. Each group receives a contiguous block of books from the shelf.

Rules:

- Every group must receive at least one book.
- No book can be split.
- The order of books must remain unchanged.

The goal is to minimise the largest total number of pages assigned to any group.

If `m > n`, it is impossible to give every group a book, so print `-1`.

## Input Format

- Line 1: Two integers `n` and `m`.
- Line 2: `n` integers representing the page counts in shelf order.

## Output Format

Print one integer: the minimum possible value of the largest total pages assigned to any group, or `-1` if `m > n`.

## Constraints

- `1 ≤ n ≤ 10^5`
- `1 ≤ m ≤ 10^5`
- `1 ≤ pages ≤ 10^4`
- Do not use built-in `max()` or `sum()`.

## Sample Input

```text id="h2j3kf"
6 3
25 46 28 49 24 20
```

## Sample Output

```text id="p3d9ua"
77
```

## Approach

1. Set the minimum possible capacity to the largest individual book.
2. Set the maximum possible capacity to the total pages of all books.
3. Use binary search to find the smallest feasible capacity.
4. For each capacity, allocate books in shelf order.
5. Start a new group whenever adding the next book would exceed the capacity.
6. If the required number of groups is at most `m`, try a smaller capacity; otherwise, try a larger one.

## Complexity Analysis

- **Time Complexity:** `O(n × log(sum of pages))` – Binary search with a linear allocation check.
- **Auxiliary Space:** `O(1)` – Only a few variables are used.
