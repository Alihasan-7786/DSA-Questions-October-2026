
# Question 3 – One-Trade Stock Profit

**Difficulty:** Easy

## Problem Statement

A trader has the closing price of a stock for each of `n` consecutive days.

She may buy one share on some day and sell it on a strictly later day. She can make at most one trade.

Given the daily prices, print the maximum value of:

`price[j] - price[i]`, where `i < j`.

If the maximum profit is negative (prices only fall) or `n = 1`, print `0` because no trade is made.

Do not use built-in `max()` or `min()`.

## Input Format

- Line 1: Integer `n`.
- Line 2: `n` integers representing the daily closing prices.

## Output Format

Print one integer: the maximum profit, or `0` if no profitable trade exists.

## Constraints

- `1 ≤ n ≤ 10^5`
- `1 ≤ price ≤ 10^9`

## Sample Input

```text
8
120 98 105 90 112 130 95 118
```

## Sample Output

```text
40
```

## Approach

1. Store the lowest price seen so far.
2. For each new day, calculate the profit using the current price and the lowest previous price.
3. Update the best profit whenever a higher profit is found.
4. Update the lowest price if the current price is smaller.
5. Print the best profit.

## Complexity Analysis

- **Time Complexity:** `O(n)` – We traverse the prices once.
- **Auxiliary Space:** `O(1)` – We use only a few variables.
