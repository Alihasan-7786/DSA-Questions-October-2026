
# Question 4 – Zero-Balance Triplets

**Difficulty:** Medium

## Problem Statement

Given an array of `n` integers, print all distinct triplets `(x, y, z)` satisfying:

- `x ≤ y ≤ z`
- `x + y + z = 0`
- The three values must come from three different positions in the array.

Triplets are distinct as value combinations. For example, `-1 0 1` should be printed only once, even if `-1` occurs multiple times.

Print the triplets in lexicographic order, one triplet per line as `x y z`.

If no triplet exists, print `None`.

**Use your own sorting routine.**

## Input Format

- Line 1: Integer `n`.
- Line 2: `n` integers.

## Output Format

Print one triplet per line in lexicographic order, or `None` if no triplet exists.

## Constraints

- `3 ≤ n ≤ 3000`
- `-10^5 ≤ value ≤ 10^5`

## Sample Input

```text
8
-1 0 1 2 -1 -4 3 -2
```

## Sample Output

```text
-4 1 3
-2 -1 3
-2 0 2
-1 -1 2
-1 0 1
```

## Approach

1. Sort the array using merge sort.
2. Fix one element at a time.
3. Use two pointers: one starting after the fixed element and one at the end.
4. If the sum is zero, store the triplet and move both pointers.
5. Skip duplicate values to avoid printing the same triplet more than once.
6. If no triplets are found, print `None`.

## Complexity Analysis

- **Time Complexity:** `O(n²)` for triplet searching, plus `O(n log n)` for merge sort.
- **Auxiliary Space:** `O(n)` for temporary merge-sort lists and recursion.
