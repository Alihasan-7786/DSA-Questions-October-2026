
# Transaction Time Window

**Difficulty:** Medium

## Problem Statement

A payment system stores transaction amounts in non-decreasing order. The array may contain duplicate amounts.

Given the array and a target value `x`, find the 0-based index of the first occurrence and the last occurrence of `x`.

If `x` does not occur, print `-1 -1`.

Use two binary searches. Do not use linear scanning or `bisect`.

## Input Format

- Line 1: Integer `n`.
- Line 2: `n` integers in non-decreasing order.
- Line 3: Integer `x`, the target amount.

## Output Format

Print two integers: the first and last index of `x`, or `-1 -1` if it is absent.

## Constraints

- `1 ≤ n ≤ 10^5`
- `-10^9 ≤ amount, x ≤ 10^9`
- The array may contain duplicates.

## Sample Input

10
5 7 7 8 8 8 8 10 12 12
8

## Sample Output

3 6

## Approach

Perform two binary searches:

1. Find the first occurrence by continuing the search towards the left after finding the target.
2. Find the last occurrence by continuing the search towards the right.

## Complexity

- **Time Complexity:** `O(log n)`
- **Auxiliary Space:** `O(1)`
