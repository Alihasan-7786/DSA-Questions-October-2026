
# Q2 - Student ID Insertion Point

**Difficulty:** Easy

## Problem Statement
Given a strictly increasing array of n student IDs and a target t:

- If t is present, print its index.
- Otherwise, print the index where t should be inserted to keep the array sorted.

Use binary search. Do not use bisect.

## Input Format
- First line contains an integer n.
- Second line contains n strictly increasing integers.
- Third line contains the target ID t.

## Output Format
Print one integer between 0 and n inclusive.

## Constraints
- 1 <= n <= 10^5
- -10^9 <= ID, t <= 10^9
- IDs are distinct and sorted.

## Sample Input
6
10 20 30 45 60 80
50

## Sample Output
4
