
# Trail Elevation Search

**Difficulty:** Medium

## Problem Statement

A hiking trail climbs strictly to a unique peak and then descends strictly.

Given an array representing the altitude at each checkpoint and a target altitude `h`, find the smallest 0-based index where `h` occurs.

If the target is not present, print `-1`.

Use binary search to find the peak, then search the increasing part and, if needed, the decreasing part. The solution must run in `O(log n)` time.

## Input Format

- Line 1: Integer `n`, the number of checkpoints.
- Line 2: `n` integers representing the mountain altitudes.
- Line 3: Integer `h`, the target altitude.

## Output Format

Print the smallest index where `h` occurs, or `-1` if it is absent.

## Constraints

- `3 ≤ n ≤ 10^5`
- `-10^9 ≤ altitude, h ≤ 10^9`
- The array is strictly increasing and then strictly decreasing.
- The peak is neither the first nor the last element.

## Sample Input

9
2 5 9 14 20 17 11 6 1
11

## Sample Output

6

## Approach

1. Find the peak using binary search.
2. Search for the target in the increasing part.
3. If it is not found, search the decreasing part.
4. Return the index or `-1`.

## Complexity

- **Time Complexity:** `O(log n)`
- **Auxiliary Space:** `O(1)`
