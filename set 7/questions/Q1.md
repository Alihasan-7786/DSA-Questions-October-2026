
# Q1 - Library Catalogue Lookup

**Difficulty:** Easy

## Problem Statement
Given a strictly increasing array of n book IDs and a query ID q, find the 0-based index of q in the array.

If q does not occur, print -1.

Use binary search with lo, hi and mid = lo + (hi - lo) // 2. Do not use bisect or list.index.

## Input Format
- First line contains an integer n.
- Second line contains n strictly increasing integers.
- Third line contains the query ID q.

## Output Format
Print one integer: the index of q, or -1 if it is not found.

## Constraints
- 1 <= n <= 10^5
- -10^9 <= ID, q <= 10^9
- IDs are distinct and sorted in increasing order.

## Sample Input
9
102 118 130 145 160 177 190 204 230
177

## Sample Output
5
