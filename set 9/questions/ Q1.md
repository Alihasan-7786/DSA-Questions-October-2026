
# Set 9 - Question 1: Budget Pairing in a Sorted Price List

**Difficulty:** Easy  
**Marks:** 16

## Problem Statement

An online shop lists its products in non-decreasing order of price. A customer with a voucher of exact value T wants a two-item bundle whose prices add up to T exactly.

Given n prices in non-decreasing order and the target T, find the two different positions (1-based, i < j) whose prices sum to T and print them separated by a space.

The input guarantees exactly one such pair of positions. The same position cannot be used twice.

## Input Format

- Line 1: Integer n.
- Line 2: n integers in non-decreasing order.
- Line 3: Integer T.

## Output Format

Print two integers i and j (1-based, i < j).

## Constraints

- 2 ≤ n ≤ 10^5
- -10^9 ≤ price ≤ 10^9
- -2 × 10^9 ≤ T ≤ 2 × 10^9
- Exactly one valid pair of positions exists.
- Do not use extra memory proportional to n.

## Sample Input

7
3 8 12 19 25 31 40
44

## Sample Output

4 5

## Approach

Use the Two Pointer technique:

1. Place one pointer at the beginning and another at the end.
2. Calculate the sum of the two prices.
3. If the sum is smaller than T, move the left pointer forward.
4. If the sum is greater than T, move the right pointer backward.
5. If the sum equals T, return both positions using 1-based indexing.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Auxiliary Space Complexity:** O(1)
