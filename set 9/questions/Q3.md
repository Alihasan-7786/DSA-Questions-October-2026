
# Set 9 - Question 3: Common Club Members

**Difficulty:** Easy  
**Marks:** 16

## Problem Statement

Two campus clubs have separate sign-up sheets of student IDs, in no particular order, and some students signed up several times.

Given arrays A (m IDs) and B (n IDs), print the distinct IDs that occur in both arrays, in increasing order separated by spaces.

If there is no common ID print None.

Use a hash set for the membership test and your own sorting routine for the output; do not use set operators (&, |, -), sorted() or list.sort().

## Input Format

- Line 1: Integers m and n.
- Line 2: m integers (sheet A).
- Line 3: n integers (sheet B).

## Output Format

Common distinct IDs in increasing order on one line, or None.

## Constraints

- 1 ≤ m, n ≤ 10^5
- 1 ≤ ID ≤ 10^9

## Sample Input

6 6
9 4 9 5 12 4
12 9 9 8 4 12

## Sample Output

4 9 12

## Approach

1. Store the IDs from array A in a hash set.
2. Traverse array B and check whether each ID exists in the first set.
3. Use another set to avoid duplicate IDs.
4. Sort the common IDs using your own Merge Sort implementation.
5. Print the sorted IDs, or None if the result is empty.

## Complexity Analysis

Let k be the number of distinct common IDs.

- **Time Complexity:** O(m + n + k log k)
- **Auxiliary Space Complexity:** O(m + k)
