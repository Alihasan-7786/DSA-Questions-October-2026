
# Set 9 - Question 5: Insert a Booking into the Calendar

**Difficulty:** Medium  
**Marks:** 26

## Problem Statement

A clinic's calendar for one doctor is a list of already consolidated bookings: closed intervals [start, end], sorted by start and pairwise disjoint (each start is strictly larger than the previous end).

A new booking arrives and must be inserted; if it overlaps or touches existing bookings they must be merged into one block.

Given n sorted, pairwise disjoint intervals and one new interval, print the updated calendar: all intervals still sorted and disjoint, with the new interval merged into any intervals that share at least one point with it.

Print one interval per line as 'start end'. The existing list is already sorted, so no sorting is needed.

## Input Format

- Line 1: Integer n.
- Next n lines: 'start end' for each existing interval.
- Last line: 'start end' of the new interval.

## Output Format

Print the resulting intervals, one per line as 'start end', in increasing order.

## Constraints

- 1 ≤ n ≤ 10^5
- 0 ≤ start ≤ end ≤ 10^9
- Existing intervals are sorted by start and pairwise disjoint (non-touching).

## Sample Input

5
1 3
6 9
12 15
18 20
22 25
8 13

## Sample Output

1 3
6 15
18 20
22 25

## Approach

1. Add all intervals that finish before the new booking starts.
2. Merge intervals that overlap or touch the new booking.
3. Add the merged booking to the result.
4. Add all remaining intervals.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Auxiliary Space Complexity:** O(n)
