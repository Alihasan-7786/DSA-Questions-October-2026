
# Set 9 - Question 4: Booking Overlap Consolidation

**Difficulty:** Medium  
**Marks:** 26

## Problem Statement

A conference-room system receives n booking requests, each a closed time interval [start, end] in whole minutes, in arbitrary order.

Overlapping bookings (and bookings that share an endpoint) are to be consolidated into single blocks so that facilities staff can see the busy periods of the room.

Merge all intervals that overlap or touch (two closed intervals merge when they share at least one point, e.g. [1,4] and [4,5] merge into [1,5], whereas [1,4] and [5,6] do not).

Print the resulting disjoint intervals in increasing order of start, one interval per line as 'start end'.

Use your own sort; built-in sort functions are not allowed.

## Input Format

- Line 1: Integer n.
- Next n lines: Two integers start and end (start ≤ end).

## Output Format

Print one merged interval per line as 'start end', ordered by start.

## Constraints

- 1 ≤ n ≤ 10^5
- 0 ≤ start ≤ end ≤ 10^9

## Sample Input

6
8 10
1 3
2 6
15 18
17 20
6 7

## Sample Output

1 7
8 10
15 20

## Approach

1. Sort the intervals by their starting values using Merge Sort.
2. Add the first interval to the result.
3. Compare each next interval with the last merged interval.
4. If the intervals overlap or touch, merge them by updating the ending value.
5. Otherwise, add the interval as a new block.

## Complexity Analysis

- **Time Complexity:** O(n log n)
- **Auxiliary Space Complexity:** O(n)
