
# Q1 – Exam Marks Ranking by Counting

**Difficulty:** Easy

## Problem Statement
A university publishes the marks of `n` students for an exam out of 100. Every mark is a whole number from 0 to 100.

Sort the marks in non-decreasing order using **Counting Sort**. Count how many times each mark from 0 to 100 occurs, then rebuild the list from those counts.

Built-in sorting and `Counter` are not allowed.

## Input Format
- First line: Integer `n`.
- Second line: `n` space-separated marks.

## Output Format
Print the sorted marks on one line, separated by spaces.

## Constraints
- `1 ≤ n ≤ 10^5`
- `0 ≤ mark ≤ 100`

## Sample Input
```text
10
78 92 65 78 100 0 65 92 78 55
```

## Sample Output
```text
0 55 65 65 78 78 78 92 92 100
```

## Approach
Create a count array of size 101. Count each mark, then traverse the count array and add each mark to the result as many times as it appears.

## Complexity
- **Time:** O(n + 101)
- **Auxiliary Space:** O(n + 101), including the result list.
