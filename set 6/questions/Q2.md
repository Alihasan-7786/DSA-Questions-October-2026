
# Q2 – Warehouse Bin Sorting

**Difficulty:** Easy

## Problem Statement
A conveyor delivers parcels tagged:
- `0` – Fragile
- `1` – Standard
- `2` – Heavy

Given `n` tags, rearrange them in place into non-decreasing order and print the result.

Aim for a single left-to-right pass using three pointers, without a general-purpose sort.

## Input Format
- First line: Integer `n`.
- Second line: `n` space-separated tags, each 0, 1 or 2.

## Output Format
Print the rearranged tags on one line, separated by spaces.

## Constraints
- `1 ≤ n ≤ 10^5`
- Each tag is `0`, `1` or `2`.

## Sample Input
```text
8
2 0 1 2 1 0 1 0
```

## Sample Output
```text
0 0 0 1 1 1 2 2
```

## Approach
Use three pointers: `low`, `mid` and `high`.

- If the current element is `0`, swap it towards the beginning.
- If it is `1`, move to the next element.
- If it is `2`, swap it towards the end.

## Complexity
- **Time:** O(n)
- **Auxiliary Space:** O(1)
