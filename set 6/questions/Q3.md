
# Q3 - Combined Attendee List

**Difficulty:** Easy

## Problem Statement
Two student clubs have sorted lists of student IDs. Merge both lists into one strictly increasing list. If an ID appears in both lists, print it only once.

Use the fact that both lists are already sorted. Built-in sorting is not allowed.

## Input Format
- First line contains two integers m and n.
- Second line contains m space-separated integers (List A).
- Third line contains n space-separated integers (List B).

## Output Format
Print the merged distinct IDs in increasing order, separated by spaces.

## Constraints
- 0 <= m, n <= 10^5
- m + n >= 1
- 1 <= ID <= 10^9
- Both lists are strictly increasing.

## Sample Input
5 4
3 8 12 20 25
5 8 20 31

## Sample Output
3 5 8 12 20 25 31
