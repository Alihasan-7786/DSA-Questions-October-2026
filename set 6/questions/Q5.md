
# Q5 - Sensor Readings with Heavy Duplicates

**Difficulty:** Medium

## Problem Statement
Given n sensor readings, sort them in non-decreasing order using quicksort with 3-way (Dutch-flag) partitioning.

Separate the elements into three groups:
1. Elements smaller than the pivot.
2. Elements equal to the pivot.
3. Elements greater than the pivot.

Use an explicit stack of index ranges instead of recursion. Choose the middle element of each range as the pivot.

Built-in sorting is not allowed.

## Input Format
- First line contains an integer n.
- Second line contains n space-separated sensor readings.

## Output Format
Print the sorted readings on one line, separated by spaces.

## Constraints
- 1 <= n <= 10^5
- 0 <= reading <= 10^9

## Sample Input
10
3 1 3 2 3 1 2 3 1 3

## Sample Output
1 1 1 2 2 3 3 3 3 3
