
# Set 1 - Question 2: First Duplicate Ticket Scan

**Difficulty:** Easy (16 Marks)

## Scenario
At the gate of a campus fest, a scanner records each ticket ID as people walk in. A ticket must only be used once.

## Problem Statement
Given a sequence of n scanned ticket IDs, find the ID of the earliest scan whose value has already appeared at an earlier position.

If no ID repeats, print -1.

The answer is determined by the position of the second occurrence, not the first occurrence.

## Input Format
- First line: Integer n
- Second line: n space-separated ticket IDs

## Output Format
Print the first repeated ticket ID, or -1.

## Constraints
- 1 <= n <= 10^5
- 1 <= ID <= 10^9

## Sample Input
8
4021 3377 5120 3377 4021 9001 5120 7

## Sample Output
3377

## Approach
Use a set to store previously visited ticket IDs. If an ID is already present, return it immediately.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
