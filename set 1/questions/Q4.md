
# Set 1 - Question 4: Warehouse Balance Point

**Difficulty:** Medium (26 Marks)

## Scenario
A warehouse has n shelves. Each shelf records a net stock change for the day. The supervisor wants to find a balance shelf where the total change on the left equals the total change on the right.

## Problem Statement
Given an array of n integers, find the leftmost index p such that the sum of elements before p equals the sum of elements after p.

The current element is excluded from both sides.

If no balance index exists, print -1.

## Input Format
- First line: Integer n
- Second line: n space-separated integers

## Output Format
Print the leftmost balance index or -1.

## Constraints
- 1 <= n <= 10^5
- -1000 <= change <= 1000

## Sample Input
6
3 -2 5 4 1 5

## Sample Output
3

## Approach
First calculate the total sum of the array. Then traverse the array while maintaining the left sum. Calculate the right sum using total - left - current element.

If both sums are equal, return the current index.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
