
# Set 1 - Question 1: Gift Card Pairing at Checkout

**Difficulty:** Easy (16 Marks)

## Scenario
An online store lets customers pay with a gift card whose balance must be used up exactly. The system must find two different items whose prices add up to the gift-card balance.

## Problem Statement
Given an array of n item prices and a target amount T, find two different positions i and j (0-based, i < j) such that:

price[i] + price[j] = T

Exactly one valid pair is guaranteed.

## Input Format
- First line: Integer n
- Second line: n space-separated item prices
- Third line: Target amount T

## Output Format
Print two space-separated indices i and j.

## Constraints
- 2 <= n <= 10^5
- 1 <= price[i] <= 10^9
- 1 <= T <= 2 * 10^9

## Sample Input
6
120 45 80 200 35 150
235

## Sample Output
3 4

## Approach
Use a dictionary to store previously visited prices and their indices. For every element, calculate the required value and check whether it already exists.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
