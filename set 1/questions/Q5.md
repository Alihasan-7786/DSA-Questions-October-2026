
# Set 1 - Question 5: Missing Roll Numbers

**Difficulty:** Medium (26 Marks)

## Scenario
A class has n students with roll numbers from 1 to n. Due to copy-paste mistakes, some roll numbers appear more than once while others are missing.

## Problem Statement
Given an array of n integers between 1 and n, find all roll numbers that do not appear in the array.

Print the missing numbers in increasing order. If every roll number appears, print None.

Try to modify the original array without using an extra array.

## Input Format
- First line: Integer n
- Second line: n space-separated integers

## Output Format
Print all missing roll numbers separated by spaces, or None.

## Constraints
- 1 <= n <= 10^5
- 1 <= entry <= n

## Sample Input
8
4 3 2 7 8 2 3 1

## Sample Output
5 6

## Approach
Use array indexing to mark the positions of visited roll numbers by changing their values to negative. Then traverse the array again and identify the positive positions.

## Complexity
- Time Complexity: O(n)
- Auxiliary Space: O(1), excluding output.
