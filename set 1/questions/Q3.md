
# Set 1 - Question 3: Second Highest Sensor Reading

**Difficulty:** Easy (16 Marks)

## Scenario
A weather station records n temperature readings in one day. The manager wants the second-highest distinct reading.

## Problem Statement
Given n integer readings, find the second-largest distinct value.

Distinct means equal values count only once.

If fewer than two distinct values exist, print None.

## Input Format
- First line: Integer n
- Second line: n space-separated integers

## Output Format
Print the second-largest distinct reading or None.

## Constraints
- 1 <= n <= 10^5
- -10^9 <= reading <= 10^9
- Built-in max(), min(), sum() and sorting are not allowed.

## Sample Input
9
31 28 35 35 29 -4 35 28 30

## Sample Output
31

## Approach
Maintain two variables to track the largest and second-largest distinct values while traversing the array once.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
