
# Q4. Merge Two Warehouse Stock Lists

## Problem Statement

You are given two sorted arrays, `A` and `B`.

Array `A` has enough extra space at the end to hold all elements of array `B`. The first `m` elements of `A` are valid sorted elements, while the remaining `n` positions are empty placeholders.

Merge array `B` into array `A` so that the final array remains sorted.

The merge must be performed in-place without creating a third array or using built-in sorting.

## Input Format
- First line contains two integers `m` and `n`.
- Second line contains `m + n` integers representing array `A`.
- Third line contains `n` integers representing array `B`.

## Output Format
Print the merged sorted array.

## Example

**Input:**
```text
4 3
1 4 7 10 0 0 0
2 5 8
```

**Output:**
```text
1 2 4 5 7 8 10
```

## Approach
Use three pointers starting from the ends of both sorted arrays and the available space in array `A`. Place the larger element at the end and move the pointers backward.

## Complexity
- Time Complexity: O(m + n)
- Space Complexity: O(1)
