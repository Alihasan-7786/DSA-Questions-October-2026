
# Q3. Out-of-Stock Items to the End

## Problem Statement

You are given an array representing the stock counts of different items.

Move all zeros to the end of the array while maintaining the relative order of all non-zero elements.

The operation must be performed in-place without creating a second array.

## Input Format
- First line contains an integer `n`, the size of the array.
- Second line contains `n` space-separated integers.

## Output Format
Print the modified array.

## Example

**Input:**
```text
9
0 14 0 3 7 0 0 9 5
```

**Output:**
```text
14 3 7 9 5 0 0 0 0
```

## Approach
Use an index to place each non-zero element in its correct position. Fill the remaining positions with zeros.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
