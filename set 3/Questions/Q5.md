
# Q5. Seat Booking Cleanup

## Problem Statement

You are given a sorted array of integers.

Remove extra occurrences of each element so that every distinct element appears at most twice.

The modification must be done in-place without creating another array.

Return the number of valid elements `k` and print the first `k` elements of the modified array.

## Input Format
- First line contains an integer `n`, the size of the array.
- Second line contains `n` space-separated sorted integers.

## Output Format
- First line prints the number of valid elements `k`.
- Second line prints the first `k` elements of the modified array.

## Example

**Input:**
```text
10
1 1 1 2 2 3 3 3 3 4
```

**Output:**
```text
7
1 1 2 2 3 3 4
```

## Approach
Use a pointer to track the position where the next valid element should be placed. Allow an element only when it differs from the element two positions behind it.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
