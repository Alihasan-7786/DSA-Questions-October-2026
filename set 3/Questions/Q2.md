
# Q2. Voice Assistant Vowel Swap

## Problem Statement

You are given a phrase containing English letters and single spaces.

Reverse the order of all vowels (`a, e, i, o, u`) in the phrase. All other characters must remain in their original positions.

Vowels should retain their original case.

## Input Format
A single line containing the phrase.

## Output Format
Print the modified phrase after reversing the vowels.

## Example

**Input:**
```text
Campus Library
```

**Output:**
```text
Campis Lubrary
```

## Approach
Use two pointers, one from the beginning and one from the end. Find vowels at both positions and swap them until the pointers meet.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
