
# Q1. Mirror Coupon Code

## Problem Statement

You are given a phrase that may contain spaces, punctuation, and a mix of uppercase and lowercase letters.

Check whether the phrase is a palindrome.

A palindrome reads the same forward and backward after:
- Ignoring spaces and punctuation.
- Converting all letters to lowercase.

Only letters and digits should be considered.

## Input Format
A single line containing the phrase.

## Output Format
Print `YES` if the phrase is a palindrome; otherwise, print `NO`.

## Example

**Input:**
```text
Was it a car or a cat I saw?
```

**Output:**
```text
YES
```

## Constraints
- The input contains printable ASCII characters.
- Do not use slicing (`[::-1]`) or `reversed()`.

## Approach
Use two pointers: one from the beginning and one from the end. Skip non-alphanumeric characters and compare the remaining characters without considering case.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)
