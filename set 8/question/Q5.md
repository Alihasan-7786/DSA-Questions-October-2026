
# Q5 – Cargo Shipping Capacity

**Difficulty:** Medium

## Problem Statement

A freight company needs to ship `n` packages in a fixed order. Each day, the ship carries consecutive packages without changing their order.

Given the package weights and the number of days `D`, find the minimum ship capacity required to deliver all packages within at most `D` days.

The capacity must be at least the weight of the heaviest package.

Do not use built-in `max()` or `sum()` functions.

## Input Format

- First line contains two integers `n` and `D`.
- Second line contains `n` integers representing package weights in shipping order.

## Output Format

Print one integer: the minimum required ship capacity.

## Constraints

- 1 ≤ D ≤ n ≤ 5 × 10⁴
- 1 ≤ weight ≤ 500
- Built-in `max()` and `sum()` are not allowed.

## Sample Input

```text
7 3
4 2 7 1 8 3 5
```

## Sample Output

```text
13
```

## Approach

Use binary search on the possible ship capacity.

1. Set the minimum capacity to the heaviest package.
2. Set the maximum capacity to the total weight of all packages.
3. Try the middle capacity.
4. Count how many days are required to ship all packages in order.
5. If the required days are within `D`, try a smaller capacity.
6. Otherwise, increase the capacity.

## Complexity

- **Time Complexity:** O(n × log(sum of weights))
- **Auxiliary Space:** O(1)
