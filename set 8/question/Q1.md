
# Square Tile Floor Planner

**Difficulty:** Easy

## Problem Statement

A contractor has `x` identical square floor tiles and wants to arrange them into the largest possible square.

Given a non-negative integer `x`, find the largest integer `s` such that:

`s × s ≤ x`

In other words, print the floor of the square root of `x`.

Use binary search. Do not use `sqrt()`, `math.isqrt()` or the `** 0.5` trick.

## Input Format

A single line containing the integer `x`.

## Output Format

Print one integer `s`.

## Constraints

- `0 ≤ x ≤ 10^18`

## Sample Input

99

## Sample Output

9

## Approach

Use binary search to find the largest integer whose square is less than or equal to `x`.

If `mid * mid ≤ x`, save `mid` as the answer and search the right half. Otherwise, search the left half.

## Complexity

- **Time Complexity:** `O(log x)`
- **Auxiliary Space:** `O(1)`
