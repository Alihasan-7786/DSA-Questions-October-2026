
# Q4 – Rotated Log Lookup

**Difficulty:** Medium

## Problem Statement

A logging service stores sequence numbers in a circular buffer. The array is originally sorted, but its starting position has been rotated by an unknown amount.

Given a rotated sorted array of `n` distinct integers and a target `t`, find and print the 0-based index of the target.

If the target is not present, print `-1`.

Use binary search in O(log n) time. Do not first locate the rotation point using a linear scan or use built-in search methods.

## Input Format

- First line contains an integer `n`.
- Second line contains `n` distinct integers forming a rotated sorted array.
- Third line contains the target integer `t`.

## Output Format

Print the index of the target, or `-1` if it is not found.

## Constraints

- 1 ≤ n ≤ 10⁵
- -10⁹ ≤ value, t ≤ 10⁹
- All values are distinct.

## Sample Input

```text id="4ldnsm"
8
15 18 22 31 3 6 9 12
9
```

## Sample Output

```text id="v4m2pu"
6
```

## Approach

Use binary search directly on the rotated array.

1. Find the middle element.
2. Identify which half is sorted.
3. Check whether the target lies within that sorted half.
4. Continue searching in the appropriate half.
5. If the target is not found, return `-1`.

## Complexity

- **Time Complexity:** O(log n)
- **Auxiliary Space:** O(1)
