
# Q2 – Seat Chart Lookup

**Difficulty:** Easy

## Problem Statement

A cinema stores ticket numbers in an R × C seating chart. Each row is sorted from left to right, and the first ticket number of each row is greater than the last ticket number of the previous row.

Given the matrix and a ticket number `t`, find the 0-based row and column of the ticket.

If the ticket is not present, print `-1 -1`.

Treat the matrix as a sorted 1-D array and use binary search with index arithmetic. Do not flatten the matrix into a new list.

## Input Format

- First line contains two integers `R` and `C`.
- Next R lines contain C integers each.
- Last line contains the target ticket number `t`.

## Output Format

Print the row and column separated by a space, or `-1 -1` if the ticket is not found.

## Constraints

- 1 ≤ R, C ≤ 300
- -10⁹ ≤ value, t ≤ 10⁹
- All values are distinct.
- Each row is increasing.
- The first value of each row is greater than the last value of the previous row.

## Sample Input

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
16
```

## Sample Output

```text
1 2
```

## Approach

Use binary search on the virtual 1-D representation of the matrix.

For every middle index:

- Row = `mid // C`
- Column = `mid % C`

Compare the matrix element with the target and adjust the search range.

## Complexity

- **Time Complexity:** O(log(R × C))
- **Auxiliary Space:** O(1)
