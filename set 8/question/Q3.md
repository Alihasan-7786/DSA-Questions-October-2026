
# Q3 – Earliest Slot After Shift Change

**Difficulty:** Easy

## Problem Statement

A hospital stores appointment start times in increasing order. After a shift change, the list is rotated by an unknown amount.

Given the rotated sorted array of distinct integers, find and print its minimum element.

Use binary search in O(log n) time. Do not use `min()` or perform a full scan.

## Input Format

- First line contains an integer `n`.
- Second line contains `n` distinct integers forming a rotated sorted array.

## Output Format

Print one integer: the minimum value in the array.

## Constraints

- 1 ≤ n ≤ 10⁵
- -10⁹ ≤ value ≤ 10⁹
- All values are distinct.

## Sample Input

```text
7
40 50 60 70 10 20 30
```

## Sample Output

```text
10
```

## Approach

Use binary search:

- If the middle element is greater than the last element, search the right half.
- Otherwise, search the left half, including the middle element.
- When both pointers become equal, that position contains the minimum.

## Complexity

- **Time Complexity:** O(log n)
- **Auxiliary Space:** O(1)
